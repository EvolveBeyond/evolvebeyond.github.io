api.py
from evoid.native import create_service, on
from evoid import Intent, Level

app = create_service("my-api")

GET_USER = Intent(
  name="GET:/users/{id}",
  level=Level.STANDARD,
  metadata={"processors": ("validate",)},
)

async def handle(intent):
  return {"id": intent.metadata["path_params"]["id"]}

on(app, GET_USER, handle)

What is EVOID?

EVOID is the reference runtime for Intent-Oriented Programming. Your data declares what it needs. The runtime handles how.

Not a framework. A runtime. Bring your own serializer, validator, and adapter. We provide the pipeline.
