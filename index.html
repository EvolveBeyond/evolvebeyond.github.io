How we work
01

Intent over implementation

Declare what you want. Let the system figure out how. We build tools that focus on intent, not mechanics.

02

Bring your own

We provide interfaces, you bring your library. Pydantic or msgspec? FastAPI or Robyn? Your choice.

03

Open by default

Every project is open source. Transparent development, community-driven, no vendor lock-in.

Example
api.py
from evoid.native import create_service, on
from evoid import Intent, Level

app = create_service("my-api")

GET_USER = Intent(
  name="GET:/users/{id}",
  level=Level.STANDARD,
)

async def handle(intent):
  return {"id": intent.metadata["path_params"]["id"]}

on(app, GET_USER, handle)
